🎯 QUICK INTEGRATION GUIDE
=====================================

1. USE METATAGS COMPONENT
   import MetaTags from './components/MetaTags.jsx';
   
   <MetaTags 
     title="Page Title"
     description="Page description..."
     url="https://..."
   />

2. USE SEOIMAGE COMPONENT
   import SEOImage from './components/SEOImage.jsx';
   
   <SEOImage 
     src="/img/project.png"
     alt="Descriptive alt text"
     lazy={true}
   />

3. USE SEO UTILS
   import { validateSEO, setPageTitle } from './utils/seoUtils.js';
   
   setPageTitle("My Page");
   const result = validateSEO();

4. ACCESS SEO CONFIG
   import SEO_CONFIG from './config/seo.config.js';
   
   console.log(SEO_CONFIG.author.name);
